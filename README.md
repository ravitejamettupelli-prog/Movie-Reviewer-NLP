
# 🎬 Movie Reviewer NLP

A Python-based Natural Language Processing (NLP) project that explores text data and sentiment labels.

## 📌 Project Overview

This project uses Python to work with text data and examine sentiment information. It demonstrates basic data handling and exploration using a Jupyter Notebook.

## 🛠️ Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Natural Language Processing (NLP)

## 📂 Project Files

- `Movie Reviewer.ipynb` — Jupyter Notebook containing the project code.
- `df.xls` — Dataset used by the notebook.
- `README.md` — Project documentation.

## 🚀 How to Run

1. Download or clone this repository.

2. Install Python and Jupyter Notebook.

3. Install the required libraries:

   ```bash
   pip install pandas numpy
   ```

4. Place `df.xls` in the same folder as the notebook.

5. Open `Movie Reviewer.ipynb` in Jupyter Notebook and run the cells.
